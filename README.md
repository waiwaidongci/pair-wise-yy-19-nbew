# 岩芯薄片显微样本编目与鉴定放行台

浏览器直接打开 `index.html` 即可使用（localStorage 持久化，无需构建）。

## 三个业务源码单元

| 单元 | 文件 | 职责 |
| --- | --- | --- |
| 入口 | `js/intake.js` | 编目、首次鉴定、复查放行、样本更正的唯一写入口；先校验后落单 |
| 判定 | `js/judgment.js` | 纯规则：放行 / 只进复查的判定与复查者校验，无副作用 |
| 持久化 | `js/store.js` | 落盘与重载；由同一份持久化数据派生总览、复查队列、履历 |

`app.js` 只是 UI 接线层，不含业务规则。

## 业务规则落点

- 每个收纳箱最多一张在途单据（在途 = 待鉴定 / 待复查）；箱号冲突整体拒绝，不产生半成品（`intake.catalog` 先校验后改状态）。
- 编号、深度或日期空白即停补录。
- 鉴定写入矿物组成、结构、偏光、孔隙占比四要素。
- 孔隙占比 > 20% 或偏光缺失 → 只进复查；复查者须与首次鉴定者不同（`judgment.judge` / `judgment.reviewerAllowed`）。
- 样本更正：旧放行取消（verdict → `cancelled`）、历史稿只读（`readonly`），按现值重判生成新稿。
- 重载后总览、队列、履历均由落盘数据重建，三者吻合。

## 自测

```bash
node tests/run-tests.js
```

覆盖：停补录、箱号冲突原子拒绝、四要素写入、20% 阈值边界、偏光缺失复查、复查者回避、更正取消旧放行与历史稿只读、重载后三视图吻合、坏档回退。
